## 🧠 Deskripsi Singkat  
Proyek ini membahas penerapan **konsep-konsep dasar dalam Metode Statistika**, khususnya dalam menghitung **estimasi rata-rata**, **standar deviasi**, **skewness (kemiringan)**, **kurtosis (keruncingan)**, serta penerapan **KNN Regresi** dan **Selang Kepercayaan** menggunakan bahasa pemrograman **Python**.  

Analisis ini bertujuan untuk memahami bagaimana data dapat diolah dan dianalisis untuk:  
- Mengestimasi parameter populasi menggunakan data sampel.  
- Mengukur penyebaran dan variasi data menggunakan *standar deviasi*.  
- Mengetahui bentuk distribusi data melalui *skewness* dan *kurtosis*.  
- Melakukan prediksi nilai kontinu dengan metode *K-Nearest Neighbor (KNN) Regression*.  
- Menghitung *Confidence Interval (Selang Kepercayaan)* untuk menentukan batas estimasi parameter populasi.
